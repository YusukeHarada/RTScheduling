# リアルタイムスケジューリングシミュレータ

Rubyで実装したリアルタイムタスクスケジューリングのシミュレータです。  
**RM（Rate Monotonic）** または **EDF（Earliest Deadline First）** のスケジューリングアルゴリズムを選択し、指定したCPU利用率の条件下でタスクセットを自動生成してシミュレーションを実行します。  
各タスクのデッドラインミス数・デッドラインオーバ量、および実行タイムラインを出力します。

---

## アルゴリズムの説明

### RM（Rate Monotonic）
周期の短いタスクほど高い優先度を与える静的優先度スケジューリングアルゴリズム。  
CPU利用率が以下の**十分条件**を満たす場合、すべてのタスクがデッドラインを守ることが保証されます。

```
U = Σ(Ci / Ti) ≤ n × (2^(1/n) − 1)
```

（`Ci`: タスクiの実行時間、`Ti`: タスクiの周期、`n`: タスク数）

### EDF（Earliest Deadline First）
絶対デッドラインが最も近いタスクを優先して実行する動的優先度スケジューリングアルゴリズム。  
CPU利用率が100%以下であればすべてのデッドラインを守ることが理論上保証されます。

- Ruby（バージョン 1.9 以上推奨）

## 使い方

### コマンドライン引数で実行（推奨）

```
ruby Task.rb <scheduler> <taskNum> <cpu>
```

| 引数        | 説明                                           |
|-------------|------------------------------------------------|
| `scheduler` | `0` = RM、`1` = EDF                           |
| `taskNum`   | 生成するタスク数（整数）                       |
| `cpu`       | CPU利用率の範囲を指定する値（下表参照、0〜6）  |

#### CPU利用率オプション（`cpu` 引数）

| 値 | CPU利用率の範囲              |
|----|------------------------------|
| 0  | 60〜70%                      |
| 1  | 70〜80%                      |
| 2  | 80〜90%                      |
| 3  | 90〜100%                     |
| 4  | 100〜110%                    |
| 5  | 110〜120%                    |
| 6  | RM十分条件以下（`U ≤ n(2^(1/n)−1)`） |

### 対話モードで実行

引数なしで起動するとプロンプトが表示され、対話形式で入力できます。

```
ruby Task.rb
```

---

## 実行例

```
ruby Task.rb 0 3 6
```

- スケジューラ: RM
- タスク数: 3
- CPU利用率: RM十分条件以下

## 出力の見方

### タイムライン

各タスクの行に、ハイパー周期の各時刻スロットの状態が表示されます。

| 記号 | 意味                             |
|------|----------------------------------|
| 数字 | そのタスクが実行されている時刻   |
| `*`  | CPUがアイドル状態               |
| `-`  | そのタスクは実行されていない時刻 |

### メトリクス

| 項目            | 説明                                         |
|-----------------|----------------------------------------------|
| `deadline miss` | デッドラインに間に合わなかったタスクの件数   |
| `deadline over` | デッドライン超過時の残り実行時間の合計       |
